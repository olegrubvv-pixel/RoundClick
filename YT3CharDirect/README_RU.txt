YT 3-CHAR DIRECT — ANDROID БЕЗ YOUTUBE DATA API И БЕЗ СЕРВЕРА

Приложение напрямую проверяет публичные страницы youtube.com/@handle с телефона.
403, 429, CAPTCHA, таймауты и неоднозначные ответы никогда не считаются свободными.
После основных проходов неподтверждённые кандидаты перепроверяются от сильных к слабым.
Рейтинг используется только для порядка повторной проверки.

Рекомендуемые настройки для 4281 кандидата:
Подтверждений: 2
Повторов ошибок: 3
Пауза между запросами: 350–700 мс

Важно: даже несколько 404 означают только отсутствие публичной страницы. YouTube может резервировать handle, поэтому окончательный ответ даёт попытка назначить handle в самом YouTube.
